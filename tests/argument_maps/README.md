ordinary roles, public authority and trust limits. Use only when this story is explicitly scoped.

With **current installed DML**, no checkout runtime PYTHONPATH, and a fresh root whose parent exists:

```sh
/path/to/installed/python /path/to/dml/tests/argument_maps/installed_story.py run /fresh/story
```

on the SAME retained history when possible. No automatic install/download/build/service is done.

its actual sources before its first computational child; bindings capture standalone support.

- Actual double/add/add/double results84/42/43/86 and SIX successful getter positions.
